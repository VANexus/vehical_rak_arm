## 3. 历史推演："归零开关"本来要动 .ioc（现已不需要，见 §5）

要加**限位开关**就得有一个配成输入的 GPIO，而"外设/引脚一律由 CubeMX 生成"（AGENTS 红线）。
板上现成的输入引脚只有 **PE0（用户按键，EXTI 双沿）** 和 **PD3（使能开关）**——都不适合当限位。
其余"空闲 IO"（`BOARD-C30D.md` §5）要变成 GPIO 输入，**必须改 `.ioc` 并重生成**。

⇒ 在 CubeMX 离线重生成问题解决之前：
- **归零只能走"撞机械死点 + 软件堵转检测"**（只改应用代码，零 .ioc 改动）；
- 或者先解决重生成（把 CubeMX 的固件仓库路径指向 FW_F4 V1.28.3），再挂限位开关。
- ⚠️ 注意：J1 底座若**能整圈旋转**，就没有"死点"可撞 → 该轴**必须**有限位/索引，
  否则不能安全归零（见 §9 的问题 3）。

## 4. 控制设计（已实现）

```
TIM6 25 kHz ISR（joint_isr；优先级 2，禁浮点/除法链/阻塞）
  每 40 µs：读 2 路编码器 CNT → 累加关节位置(counts)；急停→本周期立即刹车
  每 25 拍（1 kHz）：目标斜坡 → 定点位置 PI（设定点-实际）→ duty（限幅 + 20%/ms 斜坡）
```
- **位置环**（不是速度环）：关节要"到位"，直接对**位置误差**做 PI(+D 可选)。
  采样 40 µs、控制 1 kHz，对机械带宽（关节 ~10–50 Hz）有 20–100× 余量，足够。
- **单位**：内部统一用**电机输出轴 counts**；换算常数单点定义（同 `board_c30d.h` 纪律）：
  - `counts_per_rev = 61440`（标称；[转述] 实测 ≈61600/A 路，上板前重测）
  - 定点换算（避免浮点/除不尽）：`counts = deg10 × 1707 / 100`（1707 = 61440/3600×100，
    **0.1° = 17.07 计数**）
  - 若与电机输出轴之间有额外减速比 `k`，改写 `JOINT_CNT_PER_DEG10_X100`（**§9 问题 2**）
- **极性（实施口径与草案不同）**：**没做**底盘那套"强开环踢动 + 自动学习 sign + 存 Flash"——
  手臂关节首次上板就吃一次 55–75% 占空比的踢动，可能直接撞死点。
  A2 改为**编译期常数 `kJointSign[2]` + 一次性人工确认流程**（README §7），确认后固化。
  （若后续要自动学习，再复用底盘 `app_sign_store` 思路。）
- **软限位**：目标会被**钳位**到 `[min,max]`；**实测位置**越界 `[min-20°, max+20°]` 即
  `FAULT` + 刹车（只拦飞车，不作精度限位，**§9 问题 4**）。
- **防重力下坠**：位置环持续出力即可"顶住"（P 有下垂量、I 慢慢补掉）；但**断电必落**（无机械抱闸）。

## 5. 归零（Homing）——【已定稿】软件置零（无自动撞点）

**用户的答复：两轴"都很方便归零"。** 因此**不做**自动撞死点归零，也不需要限位开关
（限位开关本来还要改 `.ioc`，见 §3）—— 采用**人工对位 + 软件置零**：

```
规程：把 J1/J2 人工推到机械基准位 → 长按板上用户键 PE0 ≥1.5 s → 两轴当前位置 = 0.0°
      置零同时把目标设为 0°、清故障，随后位置环自动"顶住"该姿态。
      OLED 第 6 行显示 Z1 = 已归零 / Z0 = 未归零。
      （也可由 CAN SAFETY CLEAR_FAULT（0x010 cmd=6）复位位置环故障。）
```

- **未归零 = 不驱动**：`joint_zeroed()==0` 时 J1/J2 恒刹车、不接受指令。
- **未归零不算 fault**：`STATE.bit2` 只在真的位置环故障（跟随误差 >30° 或软限位越界）时置位。
- 长按检测在 25 kHz ISR 里做（40 ms 消抖 + 1.5 s 计时），**不动 .ioc、不动协议**。
  另提供 `joint_set_zero()` 供将来接 CAN / 其他触发。
- ⚠️ 增量编码器**一断电就丢零点**：每次冷启动都必须重新对位 + 置零。这是本方案的已知代价。

### 5.1 迁移前设想的"自动撞死点"为什么没采用

- 台架记录"静摩擦要 ~75% 占空比才起步"（[转述·待复测]）→ 撞死点要么不动、要么撞得很猛；
- J1 若可整圈旋转就没有死点可撞；
- 加限位开关要改 `.ioc` 并重生成（当前离线 CubeMX 重生成受阻）。

### 5.2 原状态机草案（留档，**未采用**）

```
UNKNOWN ──(收到 HOME 指令/上电自动)──▶ HOMING ──成功──▶ HOMED ──▶ 允许 ARM_CMD 落地
   ▲                                   │失败/超时
   └───────────── FAULT ◀──────────────┘
```
- 撞死点法：以低占空比单向慢速靠近死点，连续 N ms「占空比高但编码器不动」→ 判堵转 → 停 + 定义 0。
- 复用底盘堵转判据思路（底盘 `STALL_TIMEOUT_MS=2500`）；⚠️ 本板**无电流采样**，
  堵转只能靠"占空比 + 编码器不动"判断（芯片内部 OCP 6–10 A 自我保护但不回读）。

## 6. 安全语义（已定稿）

| 事件 | 舵机（J3..J6，现状） | 电机（J1/J2，A2 已实现） |
| --- | --- | --- |
| ARM 指令断流 100 ms | 保持当前位（硬件 PWM 自续） | **保持当前位置**（位置环顶住） |
| EMERGENCY_STOP | 冻结（不写 CCR） | **短路制动 + 锁存**（`joint_set_estop(1)`，下一个 25 kHz 节拍 ≤40 µs 生效） |
| 复位/掉电 | 停在原位 | **会落**（无抱闸）：掉电后 J2 自重下坠，机械上需支撑 |
| 未归零 | 无此概念 | **禁止动作**（恒刹车，`joint_zeroed()==0`） |
| 远程门关（STOP） | 保持当前位 | **不再接受新目标**，停在最后一个目标（顶住） |

> `docs/PROTOCOL.md` 里 `STATE.bit3 cmd_stale` 的语义：J1/J2 断流时**保持位置**（不是刹车），
> 与舵机等价，**无需改协议文字**。目标：帧内容一字不动 —— A2 已做到。

## 7. 精度预算（回答"精度咋样"）

| 项 | 数值 | 说明 |
| --- | --- | --- |
| 编码器分辨率 | **0.005859° / 计数** | 360°/61440，电机输出轴 |
| 协议量化 | **0.1°** = 17.07 计数 | 所以**环路比指令细 ~10 倍**，量化误差 ≤0.05° |
| 齿轮箱回差 | **~0.5–2°（典型）** [待确认] | **30:1 减速箱回差是精度的主要限制**，远大于电子分辨率 |
| 重力下坠/柔性 | 取决于负载 | J2 大臂尤其敏感 |
| 重复定位 | ≈回差量级 | 单向逼近可显著改善 |

⇒ **电子层面精度绰绰有余（0.006°/计数）**；**真正决定精度的是减速箱回差、大臂重力下垂、
以及"编码器在减速箱前"这个事实**（输出端动一点，编码器可能不感知 → 回差无法被闭环消掉）。
若要更高精度需：换低回差减速箱 / 把编码器挪到关节输出端 / 加二次编码器。

## 8. 关于"能不能 50 kHz"

**要分清是 PWM 50 kHz 还是控制环 50 kHz —— 两个答案相反。**

### 8.1 PWM 载波 50 kHz：能，但**不建议**

- 规格允许：AT8236 **逻辑输入 fPWM 上限 100 kHz** [读资料包]。
- 但 **tBLANK = 2.2 µs** 决定最小 PWM 导通时间 → 50 kHz 时**最小占空比 11 %**
  （25 kHz 时 5.5 %）→ **低速微调更差**；
- 开关损耗约翻倍；
- 且底盘还挂着"**25 kHz 能否出额定扭矩**"这条**未复测的风险**（AGENTS §4）——再拉高频率是反向操作。

**结论：PWM 保持 25 kHz。**

### 8.2 控制环 50 kHz：**可行，但收益有限**

- CPU 完全够：机械臂板**没有 25 kHz 底盘回路**，只有 2 个轴，20 µs 一拍绰绰有余。
- 但：PWM 仍是 25 kHz（一拍一个 25 kHz 周期，等于每拍只能改一次占空比），
  位置环 1 kHz 已对机械带宽有 20–100× 余量。**50 kHz 主要减少的是采样延迟（20 µs vs 1 ms）**，
  对"很硬的刚性位置环"有一点意义，对普通关节**属过设计**。
- ⚠️ **不要**因此在 20 µs 窗上做 M 法测速：巡航时 20 µs 只有 ~3 个计数，
  ±1 计数 = **33 %** 误差。测速一律用**较长的位置差分窗**（见 `vehical_rak_motion/docs/LOOP-RATE-AND-IMU-ANALYSIS.md` §1.2）。
- **建议：闭环 25 kHz（复用现成 TIM6），位置环 1–2.5 kHz。** 需要更硬再上 50 kHz，先实测占用率。

### 10.1 位置环常数（都在 `app_joint.c` 顶部，[AI] 待整定）

| 常数 | 值 | 含义 / 为何这样选 |
| --- | --- | --- |
| `JOINT_CNT_PER_DEG10_X100` | 1707 | counts/0.1°×100 = 61440/3600×100（分辨率 0.005859°/计数） |
| `JOINT_KP_NUM/DEN` | 10 / 1 | 100 counts 误差 → 10% 占空比 |
| `JOINT_KI_NUM/DEN` | 1 / 50 | 100 counts 误差持续 1 s → 20% 占空比 |
| `JOINT_I_LIMIT` | 300000 | 积分限幅（counts·ms），≈3 s 的 100 counts 误差 |
| `JOINT_DEADBAND` | 8 counts | ≈0.05°，死区内冻结积分（防噪声带里泵占空比） |
| `JOINT_DUTY_LIM` | 8500 | 85%，与底盘板 `MAX_DUTY_PERCENT` 同口径 |
| `JOINT_SLEW_Q` | 2000 / ms | 占空比斜坡 20%/ms |
| `JOINT_TGT_SLEW` | 1000 / ms | **目标**斜坡 ≈35°/s：把指令跳变变受控位移，使防飞车闸门不误报 |
| `JOINT_ERR_FAULT` | 5120 counts | 对**斜坡后目标**的跟随误差 >30° → FAULT + 刹车 |
| 软限位 | 0.0°..270.0° ±20° | 只拦飞车；范围本身待标定 |
